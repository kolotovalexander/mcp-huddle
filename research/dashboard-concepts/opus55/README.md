# Huddle — концепт «Указатель и дорожки» (opus55)

Автономный макет дашборда Huddle. Один файл `index.html`: CSS и JS внутри,
без сборки, без сети, без внешних шрифтов. Откройте файл в браузере.

Это **статический макет**. Все 24 комнаты вымышлены. Время остановлено на
24 сен 2026, 14:30. Сервер не подключён. Об этом прямо говорят штамп в шапке,
строка состояния внизу и уведомления после любых действий.

## Идея

Сейчас дашборд — три стеклянные панели равного веса. В концепте вместо них
редакционная вёрстка: «бумага и чернила», линейки вместо карточек, один
сигнальный цвет (киноварь). Главное — порядок чтения:

```
┌ Huddle  [макет]   КОМНАТЫ  ПОДКЛЮЧЕНИЕ  ОБСЛУЖИВАНИЕ   [ ⌕ Найти комнату или фразу  / ] ┐
├──────────────────┬──────────────────────────────────────────────────────────────────────┤
│ Последние|Проекты│ mcp-huddle — ~/Apps Projects/…                                       │
│ 24 комнаты · …   │ dashboard-redesign-opus55              (крупный заголовок)           │
│                  │ ОТКРЫТА / РАУНД 2 / ВЛАДЕЛЕЦ CLAUDE / …                              │
│ Сегодня       9  ├──────────────────────────────────────────────────────────────────────┤
│ ● dashboard-…    │ ДОРОЖКИ: Claude  пишет ответ  ─▢──■────────•──|  пишет сводку         │
│ ● wake-claim-…   │          Codex   работает     ────■──•─────■──|  читает dashboard.js  │
│ Вчера         5  ├──────────────────────────────────────────────────────────────────────┤
│ ○ opencode-…     │ [Раунд 1]                                                            │
│ Пн, 21 сентября  │ HUMAN    ЗАПРОС → ВСЕМ                                               │
│ ○ structured-…   │ 11:01    Я потерял комнату structured-brief-test…                    │
│                  ├──────────────────────────────────────────────────────────────────────┤
│                  │ От имени Human [запрос|комментарий] кому [всем ▾]      [ДОБАВИТЬ]    │
├──────────────────┴──────────────────────────────────────────────────────────────────────┤
│ ■ Статический макет…     / поиск  [ ] соседняя     тема [бумага|чернила] A− 100% A+ …   │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **Указатель** слева — как оглавление книги. Крупные курсивные заголовки групп
   («Сегодня», «Вчера», «Пн, 21 сентября» или название проекта с путём).
   Строка комнаты: знак статуса (● открыта, ○ закрыта, ✓ решена), имя моноширинным
   шрифтом, время, проект и участники.
2. **Комната** справа: крупное имя, факты одной строкой.
3. **Дорожки агентов** — вместо правой панели активности. У каждого агента своя
   строка: фаза (работает, думает, лимит запросов…), шкала времени с отметками
   его сообщений, текущая деталь. Сразу видно, кто молчит. Клик по отметке —
   прыжок к сообщению. Клик по имени — журнал агента. Дорожки сворачиваются.
4. **Стенограмма** — как сценарий пьесы: слева кто и когда, справа тип
   («Запрос → Codex», «Ответ», «Итог») и текст. Раунды — жирные линейки.
   Итог обведён рамкой.

## Главное взаимодействие — поиск

Задача: пользователь потерял `structured-brief-test` в длинном списке.

- Большая чёрная кнопка в шапке «Найти комнату или фразу из переписки»,
  клавиши `/` и `Ctrl/⌘+K`. Под списком комнат — ссылка «Не находите нужную?».
- Поиск открывается отдельным экраном, а не выпадашкой. Огромное поле ввода.
- Выдача разделена на две колонки: **«Совпало в названии»** и
  **«Совпало в переписке»**. Поэтому ясно, почему комната попала в результат.
  У комнаты сказано «ещё N в переписке». У сообщения видно комнату, автора, тип,
  время и фрагмент с подсветкой.
- Фильтры: «везде / только названия / только переписка», «и в закрытых комнатах».
- Дефис, точка, подчёркивание и пробел равны: «structured brief» находит
  `structured-brief-test`. Буква «е» находит «ё».
- Набрали в русской раскладке («ыекгсегкув») — предложит «structured».
- `↑ ↓ Enter`: комната открывается сразу на совпадении. Сверху жёлтая полоса
  «3 совпадения в переписке · ↑ ↓ · сбросить подсветку». Сообщения с
  совпадением помечены ромбом.

## Настройки без огромного поповера

Поповер «Вид» разобран на три места:

| Было в поповере / шапке               | Стало                                                   |
|---------------------------------------|---------------------------------------------------------|
| тема, скин, палитра, язык             | строка состояния: тема (бумага/чернила), размер текста, плотность строк |
| список комнат: последние / по проектам| переключатель прямо над списком                          |
| MCP-подключение, env, подсказка агенту| вкладка «Подключение» с кнопками «копировать»            |
| «Закрыть все», «Удалить закрытые», «Снести всё» в шапке | вкладка «Обслуживание»: от мягкого к необратимому, «Снести всё» требует вписать СНЕСТИ |

Скин и шесть палитр убраны сознательно: у концепта одна сильная вёрстка
в двух вариантах света. Язык интерфейса в макете только русский.

## Особенности дизайна

1. Бумага и чернила: тёплый фон, линейки 1–2 px, ноль стекла, теней и скруглений.
2. Шрифты системные: антиква для текста, моноширинный для имён комнат и служебных
   данных. Сетевых шрифтов нет.
3. Один акцентный цвет: открытые комнаты, работающие агенты, активная вкладка.
4. Выбранная строка — инверсия (чернила по бумаге наоборот), а не подсветка карточки.
5. Дорожки агентов как партитура: время по горизонтали, форма отметки — тип
   сообщения (▢ запрос, ■ ответ, • реплика, рамка — итог).
6. Навигация с клавиатуры: `/` поиск, `[` `]` соседняя комната, `Esc` сбросить.

## Ограничения

- Данные статичные. Отправка сообщения добавляет его только на страницу
  с пометкой «только на этой странице». Кнопки закрытия и удаления показывают
  уведомление и ничего не делают.
- Нет авторизации по `MCP_HUDDLE_TOKEN`, SSE-потоков и живых журналов агентов.
- Адрес `http://127.0.0.1:8014/mcp` на вкладке «Подключение» — пример.
- Поиск по тексту в продукте потребует серверного прохода по сообщениям
  (новый маршрут или расширение API). В макете он идёт по данным в памяти.
- Нет i18n (многоязычия): тексты только на русском.
- Макет не проверялся тестами и в браузере автоматически — только чтением кода.
- Настройки вида сохраняются в `localStorage` под ключом `huddle-mock-opus55`,
  если браузер разрешает это для `file://`.
