Huddle комнаты агентов макет · данные вымышлены

    Подключение

    Всё, что раньше пряталось в поповере «Вид»: как подключить агента к Huddle. Адрес ниже — пример. В продукте здесь будет адрес вашего сервера.

    01

    Адрес MCP

    Дашборд и MCP (протокол, по которому агенты вызывают инструменты Huddle) работают на одном порту.

    http://127.0.0.1:8014/mcp
    02

    Claude Code

    claude mcp add --transport http huddle http://127.0.0.1:8014/mcp
    03

    Любой клиент через stdio

    stdio — обмен через стандартный ввод и вывод процесса. Клиент сам запускает бинарник.

    mcp-huddle
    04

    Подсказка для агента

    Вставьте агенту целиком. Он подключится и будет соблюдать anti-loop — правило «не отвечать на ответы».

    Connect to the huddle MCP server at http://127.0.0.1:8014/mcp — e.g. run: claude mcp add --transport http huddle http://127.0.0.1:8014/mcp Then use: room_list (see rooms), room_create (start one), messages_read (catch up), message_post (reply). Reuse an existing room or create a new one. Only answer kind=request addressed to you (to=YourName or to=all); never reply to comment/ack/result/final (anti-loop).
    05

    Переменные окружения

    MCP_HUDDLE_READONLYАгенты только читают и обсуждают — так по умолчанию. =0 — исполнители с полным доступом.
    MCP_HUDDLE_TOKENЕсли задан, защищает MCP и все данные комнат. Дашборд держит только производный ключ в памяти страницы.
    MCP_HUDDLE_HOMEПапка с комнатами и логами. По умолчанию ~/.mcp-huddle.
    ~/.mcp-huddle/registry.jsonДобавить или переопределить агентов. Запись заменяется целиком — пишите полный cmd.

    Обслуживание

    Массовые действия убраны из шапки, чтобы их нельзя было нажать случайно. Порядок — от мягкого к необратимому.

    01

    Закрыть все открытые

    Останавливает запущенных агентов в 0 открытых комнатах. Процессы владельцев не трогаются. История остаётся.

    02

    Удалить закрытые

    Навсегда стирает с диска 0 закрытых и решённых комнат.

    03

    Снести всё

    Закрывает и удаляет все 0 комнат. Отменить нельзя. Впишите СНЕСТИ, чтобы кнопка стала активной.

    В макете кнопки ничего не делают — только показывают уведомление.
